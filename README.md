# Automotive Project Planning & Cost Control

**Portfolio Project 02 of 05 | Microsoft Project (MSP)**

## Project Overview

This project focuses on planning and cost control for an automotive production line expansion scenario using Microsoft Project.

The project schedule covers the major phases of project execution, from project management and engineering design to procurement, installation, automation, testing, and final handover.

The report demonstrates the use of project scheduling, baseline planning, activity dependencies, progress tracking, and cost reporting.

## Project Scope

The project includes the following work packages:

- Project Management
- Engineering & Design
- Procurement
- Site Preparation & Installation
- Automation & Integration
- Testing & Commissioning
- Handover & Closeout

## Key Project Control Features

- Work Breakdown Structure (WBS)
- Activity scheduling and duration management
- Baseline start and finish dates
- Predecessor relationships and activity dependencies
- Activity progress tracking
- Actual and remaining duration fields
- Fixed-cost tracking
- Baseline cost overview
- Monthly project cost reporting

## Project Reports

### 1. Project Overview
Provides a consolidated view of the project schedule, work packages, activity durations, baseline dates, progress percentages, and dependencies.

### 2. Project Cost Overview
Presents the project budget and activity-level fixed costs, supporting cost visibility across the main work packages.

Intended to present the distribution of project costs across the reporting timeline.
